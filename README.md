# 練馬区 神社・仏閣マップ（知名度マップ）

練馬区内の神社・仏閣（祠・地蔵・境内社を含む）362件を、所在地と**知名度**で地図化した閲覧専用サイトです。

- 知名度でピンを色分け（灰＝無名 → 琥珀 → 赤＝地域で有名）
- 「もっとも知られていない」神社・仏閣 **ワースト10ランキング**
- 名称・地域・区分・知名度での検索／絞り込み
- スマートフォン対応（地図全画面＋ボトムシート）
- 各施設の詳細・Googleマップ経路・出典リンク

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（単一HTML） |
| `data.js` | 施設データ（**内容の変更はこのファイルのみ編集**） |

地図：Leaflet ＋ 国土地理院「淡色地図」（商用利用可・APIキー不要）
座標：国土地理院 住所検索APIでビルド時に生成し静的保存

## 出典・注意

知名度は参拝規模・検索・地図掲載・地域記録などを手がかりにした**相対的な推定値**（2026年10月時点）で、公的な認定ではありません。所在地・一覧は本人調査、参照は 猫の足あと（tesshow.jp）・ホトカミ・東京都宗教法人名簿 ほか。
